# 🛡️ CyberGRC & SGSI Enterprise Platform — AC Engenharia

> **Plataforma Corporativa Integrada de Governança, Riscos, Conformidade (GRC), Privacidade de Dados (LGPD) e Sistema de Gestão de Segurança da Informação (SGSI — ISO/IEC 27001:2022 & ISO/IEC 27701)** projetada especificamente para o setor de **Engenharia e Construção Civil**.

---

## 📌 1. O Que é o Sistema?

O **CyberGRC & SGSI Enterprise Platform** é uma solução *all-in-one* de governança cibernética, privacidade e conformidade regulatória desenvolvida sob medida para a **AC Engenharia**.

A plataforma centraliza, em um único ecossistema auditável, a gestão de **Sede Corporativa, Canteiros de Obras e Estandes Comerciais**, integrando controles técnicos de cibersegurança (SIEM, EDR, segmentação de redes VLAN, criptografia de endpoints e contenção de incidentes) com obrigações jurídicas e trabalhistas críticas da construção civil (LGPD, ANPD, NR-07, NR-18 e Código Civil).

---

## 🎯 2. Qual é a Proposta do SGSI na AC Engenharia?

O setor de engenharia e incorporação lida simultaneamente com **propriedade intelectual de alto valor** (projetos executivos BIM/CAD `.rvt` e `.dwg`, orçamentos estratégicos no Sienge ERP), **dados pessoais sensíveis em larga escala** (biometria facial em catracas de canteiros e prontuários médicos ocupacionais ASO/PCMSO de operários próprios e empreiteiros) e **dados financeiros/patrimoniais de compradores** (CRM Comercial).

A proposta do SGSI da **AC Engenharia** fundamenta-se em **6 Pilares Estratégicos**:

1. **Conformidade Multinormativa Integrada (ISO 27001 + ISO 27701 + LGPD + NRs):**
   - **ABNT NBR ISO/IEC 27001:2022 & 27701:** Declaração de Aplicabilidade (SoA) dinâmica cobrindo controles organizacionais, de pessoas, físicos e tecnológicos.
   - **LGPD (Lei nº 13.709/2018):** Inventário de Operações de Tratamento (RoPA Art. 37), Relatório de Impacto (RIPD Art. 38) e Atendimento aos Direitos dos Titulares (DSAR Art. 18 com SLA de 15 dias).
   - **Resolução CD/ANPD nº 15/2024:** Fluxo automatizado de resposta a incidentes com cronômetro regressivo de **3 dias úteis** para comunicação formal à ANPD e aos titulares.
   - **NR-07 (PCMSO) & NR-18 (Condições de Segurança na Indústria da Construção):** Guarda legal de prontuários médicos por 20 anos com sigilo estrito e homologação de empreiteiras terceirizadas.
   - **Código Civil Art. 618:** Tabela de temporalidade e retenção decenal (10 anos) para contratos e projetos estruturais pós-emissão do Habite-se.

2. **Blindagem de Canteiros de Obras e Ciclo de Vida da Biometria Facial (Art. 11 LGPD):**
   - Monitoramento individualizado por obra/unidade, exigindo isolamento em **VLAN dedicada** para catracas faciais e CFTV, sem retenção de imagem bruta facial (uso exclusivo de templates criptográficos) e **rotina formal de expurgo seguro pós-Habite-se** na desmobilização do canteiro.

3. **Proteção Comercial e Prevenção ao "Risco Cyrela" (Estandes de Vendas & CRM):**
   - Governança sobre imobiliárias parceiras e corretores autônomos com controle de **Opt-in explícito** e assinatura obrigatória do **Termo de Confidencialidade e Não Repasse de Leads Comerciais**, prevenindo condenações judiciais e sanções da ANPD por compartilhamento indevido de dados de compradores com terceiros (arquitetos, marcenarias, financeiras).

4. **Defesa Ativa contra Ransomware em Servidores de Engenharia (BIM/CAD & ERP):**
   - Monitoramento contínuo via **Wazuh SIEM / EDR**, auditoria de criptografia de disco **BitLocker/FileVault** em notebooks de campo, verificação de backups imutáveis (regra 3-2-1-1-0 com Object Lock) e isolamento de portas de switch via **MikroTik (VLAN 99 de Quarentena)**.

5. **Cultura Contínua de Privacidade e Plano Priorizado de Adequação:**
   - Execução guiada por um **Roadmap de 24 Tarefas Priorizadas (Fases 1 a 4 — do Custo Zero à Alta Complexidade)** e um cronograma anual de **52 Semanas de Campanhas de Conscientização ANPD** com disparo multicanal.

6. **Rastreabilidade Forense e Validade Jurídica Inviolável:**
   - Todas as ações, aprovações de evidências e **Assinaturas Eletrônicas de Documentos** geram blocos encadeados na **Trilha de Auditoria Forense (Merkle Chain SHA-256)** com carimbo de tempo, garantindo integridade probatória para auditorias externas e perícias judiciais.

## 🔐 4. Arquitetura de Segurança e Hardening (Defesa em Profundidade)

O sistema foi submetido a uma reestruturação completa de segurança seguindo o padrão **OWASP Top 10** e **ISO/IEC 27001**:

- **Autenticação Criptográfica HMAC-SHA256 (`server/security.ts`):** Emissão de tokens assinados no servidor com expiração, revogação imediata no logout (`POST /api/auth/logout`) e encerramento automático de sessão por inatividade (30 min).
- **Acesso Exclusivo por Convite + Google Workspace SSO:** Novos usuários só conseguem autenticar via Google OAuth 2.0 se pertencerem ao domínio corporativo autorizado e possuírem convite prévio cadastrado pelo Administrador Principal (Zero-Trust Onboarding).
- **Proteção Anti-Brute-Force & Rate Limiting:** Bloqueio automático de IP/conta após 5 tentativas inválidas de login e limite de requisições por minuto na API.
- **Sanitização Profunda (Anti-XSS & Anti-Prototype Pollution):** Filtro recursivo no backend e escapamento estrito no cliente, além de remoção absoluta de hashes/senhas em qualquer resposta JSON ou armazenamento local.
- **Cabeçalhos HTTP Hardened:** `Content-Security-Policy (CSP)`, `Strict-Transport-Security (HSTS)`, `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff` e `Permissions-Policy`.

## 🐳 5. Arquitetura de Produção Multi-Container (`docker-compose.yml`)

A stack de produção para VPS é dividida em **4 serviços isolados** conectados pela rede interna `cybergrc-enterprise-net`:

| Serviço | Container | Tecnologia | Porta (Dedicada Anti-Conflito) | Função |
| :--- | :--- | :--- | :--- | :--- |
| **`frontend`** | `cybergrc-frontend` | Nginx 1.27 Alpine + Vite SPA | **`4300:80`** | Serve a interface web estática otimizada com Gzip, cabeçalhos de segurança OWASP e faz Proxy Reverso de `/api/` para o container `backend`. |
| **`backend`** | `cybergrc-backend` | Node.js 20 Alpine + Express | **`127.0.0.1:4301:4301`** | API RESTful executando em usuário não-root (`cybergrc`), motor de segurança HMAC-SHA256 e sincronização transacional com o PostgreSQL. |
| **`db`** | `cybergrc-postgres` | PostgreSQL 17 Alpine | **`127.0.0.1:5439:5432`** | Banco de dados relacional de produção com volume persistente `cybergrc-postgres-data` e healthcheck automático. |
| **`adminer`** | `cybergrc-adminer` | Adminer Latest | **`127.0.0.1:8480:8080`** | Gerenciador visual do banco restrito exclusivamente ao `localhost` (acessível com segurança via túnel SSH). |

## 🧹 6. Estado de Instalação Limpa (Zeroed State)

Este repositório sobe por padrão em **Instalação 100% Limpa (Zeroed State)** — sem obras fictícias e sem dados de demonstração pré-preenchidos — mantendo apenas a estrutura essencial da **AC Engenharia** pronta para preenchimento do zero:

- **1 Conta de Administrador Principal** (configurada via variáveis de ambiente no arquivo `.env` da VPS).
- **1 Unidade Matriz Essencial:** `MATRIZ-001` — **Escritório Central (Matriz)** (`0` canteiros fictícios).
- **Cadastros Operacionais Zerados (`0` registros):** `0` Riscos, `0` Processos RoPA, `0` Solicitações DSAR, `0` Terceiros/DPAs, `0` Alertas SIEM, `0` Ativos de TI, `0` Incidentes CSIRT, `0` Evidências e `0` Assinaturas.
- **Catálogos Normativos em `0%`:**
  - **11 Controles ISO 27001 (SoA):** todos em status `"Não Implementado"` (`0%`).
  - **24 Tarefas do Plano Priorizado:** todas desmarcadas (`0%` concluído).
  - **52 Semanas de Campanhas ANPD:** todas desmarcadas (`0%` enviadas).
  - **7 Conectores de API:** todos em status `"Não Configurado"` e sem tokens fictícios.
  - **37 Modelos, Atas e Termos Oficiais da AC Engenharia:** disponíveis na biblioteca para geração e assinatura.

## 📚 7. Tutoriais de Implantação, Operação e Manutenção

### 🛠️ Tutorial 1: Como Subir na VPS com Docker Compose (Recomendado para Produção)

#### Passo 1: Instalar o Docker e Docker Compose na VPS (Ubuntu / Debian)
Conecte-se à sua VPS via SSH e execute:
```bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
```

#### Passo 2: Clonar o Repositório na VPS
```bash
sudo mkdir -p /opt/cybergrc
sudo chown -R $USER:$USER /opt/cybergrc
git clone https://github.com/manoelmgsantos-dotcom/SGSI-AC.git /opt/cybergrc
cd /opt/cybergrc
```

#### Passo 3: Configurar o Arquivo `.env` de Produção
Crie o arquivo `.env` a partir do modelo `.env.example` e defina suas credenciais reais (o arquivo `.env` nunca sobe para o GitHub):
```bash
cp .env.example .env
nano .env
```
Preencha as variáveis no seu `.env`:
```env
NODE_ENV=production
APP_PORT=4300
BACKEND_PORT=4301
POSTGRES_PORT=5439
ADMINER_PORT=8480

# Credenciais do PostgreSQL 17
POSTGRES_DB=cybergrc
POSTGRES_USER=cybergrc
POSTGRES_PASSWORD=SUA_SENHA_FORTE_DO_BANCO
DATABASE_URL=postgresql://cybergrc:SUA_SENHA_FORTE_DO_BANCO@db:5432/cybergrc

# Credenciais do Administrador Principal (Master Setup)
BOOTSTRAP_ADMIN_EMAIL=seu-email-admin@suaempresa.com.br
BOOTSTRAP_ADMIN_PASSWORD=SUA_SENHA_FORTE_DE_ADMIN

# Chave Criptográfica de Sessão e Token HMAC-SHA256
SESSION_SECRET=gere-uma-chave-secreta-longa-e-aleatoria-aqui

# Domínio da VPS e Client ID do Google Workspace (Opcional)
APP_DOMAIN=sgsi.suaempresa.com.br
GOOGLE_CLIENT_ID=seu-client-id.apps.googleusercontent.com
```

#### Passo 4: Construir e Subir os 4 Containers em Modo Limpo
Execute o script automatizado de deploy:
```bash
chmod +x deploy.sh
./deploy.sh --clean
```
Ou suba diretamente via Docker Compose:
```bash
docker compose up -d --build
```
Após alguns segundos, acesse no navegador:
- **Painel Principal Web (Porta `4300`):** `http://IP_DA_SUA_VPS:4300`
- **Healthcheck da API:** `http://IP_DA_SUA_VPS:4300/api/health`

### 💻 Tutorial 2: Como Rodar Localmente (Ambiente de Desenvolvimento)

1. **Instale as dependências Node.js:**
   ```bash
   npm install
   ```
2. **Crie seu arquivo `.env` local:**
   ```bash
   cp .env.example .env
   ```
3. **Zere/Inicialize a base limpa (opcional):**
   ```bash
   npm run db:reset
   ```
4. **Inicie o servidor completo (Frontend Vite na porta `4300` + Backend Express na porta `4301`):**
   ```bash
   npm run dev
   ```

### 🔄 Tutorial 3: Comandos Úteis de Manutenção, Reset e Backup na VPS

- **Verificar o status e saúde dos 4 containers:**
  ```bash
  docker compose ps
  ```
- **Acompanhar os logs em tempo real (Frontend, Backend e Banco):**
  ```bash
  docker compose logs -f frontend backend db
  ```
- **Zerar novamente o banco de dados para Instalação Limpa (Zeroed State):**
  ```bash
  docker compose exec backend node scripts/reset-db.mjs
  ```
- **Realizar Backup Completo (Dump SQL) do PostgreSQL 17:**
  ```bash
  docker compose exec db pg_dump -U cybergrc cybergrc > backup_sgsi_$(date +%F).sql
  ```
- **Restaurar um Backup SQL no PostgreSQL 17:**
  ```bash
  cat backup_sgsi_2026-11-11.sql | docker compose exec -T db psql -U cybergrc -d cybergrc
  ```
- **Acessar o Adminer (`127.0.0.1:8480`) com Segurança via Túnel SSH:**
  Na sua máquina local, abra um terminal e crie o túnel SSH para a VPS:
  ```bash
  ssh -L 8480:127.0.0.1:8480 usuario@IP_DA_SUA_VPS
  ```
  Em seguida, acesse `http://localhost:8480` no seu navegador local.
- **Atualizar a VPS quando houver novas alterações no GitHub:**
  ```bash
  cd /opt/cybergrc
  git pull origin main
  docker compose up -d --build
  ```
